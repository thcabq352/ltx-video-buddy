# Model selection audit

Inventory of every place this repo picks a model, checkpoint, or GGUF by a fixed order or a silent fallback. Line numbers are from `cursor/10eros-v15-gguf-a523` at the plan commit. The planned change is the route-then-model decision in `docs/MODEL_SELECTION_PLAN.md`.

Silent means the user is not told why this file won or why another file lost. A one-line "preference #1" label is still silent about the losers.

## VRAM source used by the scorer

`master_agent/config.py:197-248` sets `VRAM_GB` from `VRAM_GB` env, else `nvidia-smi` memory.total, else 16, and records `VRAM_SOURCE`. That number is total capacity, not free memory. `format_doctor_line` (`vram_policy.py:1017`) prints it. PR #92 adds `probe_cuda_mem` / `doctor_vram_gb` (min of declared and free). That code is not on this branch and will not be copied. The scorer uses declared `VRAM_GB` and, when `nvidia-smi` answers, `memory.free` as probed free VRAM. The reason says which source it used.
