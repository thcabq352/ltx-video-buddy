# Prompts

Working prompt templates that produced a reusable result.

One file per template. Schema is in [`../AGENTS.md`](../AGENTS.md).
`EXAMPLE-` files are not runs. The 2026-09-29 Blaze concert and pier
briefs are recorded prompt text for the remake recipe. They are not
tower renders.

Copy `EXAMPLE-h3-cold-brew-commercial.md` when you record a real
prompt, drop the `EXAMPLE-` prefix, set `status: recorded`, and replace
every placeholder with values from that run.
